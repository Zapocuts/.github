# Security Policy

We take the security of ZapoCuts and the people who use it seriously. If you believe you have found a security vulnerability in any ZapoCuts repository or service, please report it privately as described below.

## Reporting a vulnerability

**Do not report security vulnerabilities through public GitHub issues, pull requests or discussions.**

Report vulnerabilities privately using one of these options:

1. **GitHub private vulnerability reporting.** If it's enabled on the affected repository, open the repository's **Security** tab and select **Report a vulnerability**.
2. **Email.** Send details to **[SECURITY_CONTACT_EMAIL — placeholder, to be added before publishing]**.

Please include as much of the following as you can:

- The affected repository, component or service
- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- Any relevant versions, configuration or environment details
- Whether you believe the issue is already being exploited

## What to expect

- We aim to acknowledge your report within **3 working days**.
- We will investigate, keep you updated on our progress and let you know when the issue is resolved.
- If we need more information, we'll contact you using the channel you reported through.
- With your permission, we're happy to credit you once a fix is released.

## Responsible disclosure

We ask that you:

- Give us reasonable time to investigate and fix the issue before sharing it publicly or with third parties.
- Agree a disclosure timeline with us. We'll work with you to coordinate it.
- Make a good-faith effort to avoid privacy violations, data destruction and service disruption.
- Access only the minimum data needed to demonstrate the issue. Do not view, modify, keep or share other people's data.
- Do not use social engineering, phishing or physical attacks, and do not run denial-of-service tests.

## Supported versions

ZapoCuts is in active development and has no long-term supported releases yet. Security fixes are applied to the latest version on each repository's default branch.
